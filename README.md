# TAIPrompts

**TAIPrompts** — веб-генератор промптов для ChatGPT и других нейросетей.
Выбираешь категорию → настраиваешь параметры → получаешь готовый промпт под свою задачу.

🌐 Сайт: [https://timoshamoscow.github.io/taiprompts.github.io/](https://timoshamoscow.github.io/taiprompts.github.io/)

---

## 🚀 О проекте

TAIPrompts создан как удобная платформа для **быстрой и понятной генерации промптов**, с упором на:

* читабельность,
* практичность,
* и вайбкодинг.

---

## 🧩 Что есть сейчас

* **Многостраничный сайт** (отдельные страницы под разделы)
* **Категории промптов** (выбор карточкой)
* **Кастомизация в модальном окне** (параметры + ввод идеи + стиль ответа)
* **Генерация итогового промпта + копирование**
* **Адаптивный интерфейс** (нормально работает на телефоне)
* **PWA-поддержка** (установка как приложение, где доступно)

---

## 🛠️ Как пользоваться

1. Открой генератор
2. Выбери категорию
3. Настрой параметры в модалке
4. Опиши идею
5. Нажми «Сгенерировать»
6. Скопируй промпт и используй в нейросети
